# Procedure: GAIN Mesh Operations & Peer Federation

> Canonical Standard Operating Procedure · Hath0r Agentic Framework  
> Updated: 2026-10-05

## 1. Operational Command Steps

### Step 1: Mesh Health Check
```bash
hath0r mesh status
```

### Step 2: Peer Discovery
```bash
hath0r mesh peers
```

### Step 3: Peer Connectivity Verification
```bash
hath0r mesh ping --peer-id agent-02
```

### Step 4: Route Remote AgentGraph Query
```bash
hath0r mesh route --peer-id agent-02 --query "governance"
```

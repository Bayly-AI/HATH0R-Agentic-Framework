# Hath0r Canonical Knowledge & Tool Pack

This folder contains the **complete, self-contained basic set of knowledge and tool specifications** for the Hath0r ecosystem.

When building or bootstrapping Hath0r from scratch using **only** the `release/prompts/` folder, this knowledge pack is hydrated into:
1. **Hath0r MCP**: As the canonical knowledgebase indexed for vector and semantic search.
2. **Hath0r CLI**: As the foundational memory graph (`.hath0r/memory/graph.json`) and AgentGraph rules substrate.
3. **Hath0r ATC**: As the runbook and governance registry.
